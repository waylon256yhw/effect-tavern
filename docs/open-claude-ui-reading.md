# 读 open-claude-ui：Claude Desktop 的样式地基，拆开看哪些是地基

材料：https://github.com/Caho1/open-claude-ui ，2026-10-19 最后一次提交。自称用 REA 反编译 macOS Claude Desktop（`@ant/desktop v2.37337.1`，2026-10-13 构建）得到的 CSS 令牌、关键帧、30 个 React 组件和一本 3000 行手册。读它的目的只有一个：我们的客户端要先打一层中性的地基，再谈品牌；Claude Desktop 恰好在 1.x → 2.0 走了同一条路（暖纸色 → 冷白、20px 胶囊 → 12px、32px 控件 → 24px），把它的地基摊开看，哪些值得拿。

## 〇、从高处看

三个问题，按顺序。

**哪些是真提取、哪些是模型编的。** CSS 令牌层可信：35 阶灰阶和橙阶、四层 surface、alpha 边框阶梯、双环阴影、`@property` 驱动的滚动渐隐、带哈希的类名（`_grapheme-reveal_1plog_1`、`timeline-quiet-dot`）、`--cds-assistant-message-text-stop: clamp(0px, (100% - 384px) * .175, 56px)` 这种没人会凭空编的值。React 组件层是重建的：`ChatComposer` 里写死 "Claude 3.7 Sonnet"、用 💡 emoji 当图标，`useClaudeScrollPinning` 是教科书式的 pin-to-bottom，这些是作者照着截图写的参考实现，不是产物。手册的散文全是"物理学 / 着色器 / 视网膜光渗"一类的腔调，读数值，跳过形容词。无法独立核验，但令牌层和我们对 Claude 界面的直接观感一致。

**哪些是给 Electron 桌面端打的补丁，与我们无关。** 交通灯几何补偿、`-webkit-app-region`、Vibrancy、多窗口 IPC、离线队列、Web Audio 提示音、画廊 pan/zoom、Cowork 看板。整个第五、六篇。

**哪些我们已经有更好的形式，或产品决定走反方向。**

- IME：它的 `ChatComposer` 只看 `isComposing || keyCode === 229`，漏掉 WebKit 在 compositionend 之后派发的那一个回车；Issue #20 才补了 500ms 窗口、只拦 Enter。我们的 `ime.ts` 用 compositionend 后的一个宏任务标记，更窄、不靠时间常数。回车语义也相反：它回车发送、Shift 回车换行；我们回车换行、⌘↵ 发送（设计稿定的，手机用按钮）。
- 滚动：它钉底（40px 容差、150ms 冷却、35vh 底部垫）。我们的设计稿是"新的一节移到屏幕顶部、下方留一屏空白、视口不动"，是反方向的决定。它的两个常数（用户输入后 150ms 内不动视口、离底 120px 出回到底部按钮）可以借到我们的跟底表里。
- 结构：它是 user 气泡 + assistant 无框正文；我们是读者的话 + 一张卡片。不改。

剩下的就是地基本身。

## 一、值得拿的地基（数值层）

| 层 | Claude Desktop 2.0 的做法 | 对我们的意义 |
| --- | --- | --- |
| 底色 | 不是"bg / card"两个色，是一条灰阶上的四个台阶：surface-0 画布 `#f9f9f7`、1 页面 `#fcfcfb`、2 卡片 `#fff`、3 输入框与浮层 `#fff`；深色 `#0b0b0b / #151515 / #1a1a19 / #20201f`。无色相。 | 四层比两层够用且不多：画布（桌面侧栏后面）、页面、卡片、输入框。我们的设计稿恰好也有 canvas / bg / card / surface 四个，只是染了紫。 |
| 边框 | 不用实色边框，用 alpha 阶梯：5% / 10% / 20% / 35% 的黑（深色换白 5 / 9 / 18 / 30%）。边框用 `box-shadow: 0 0 0 1px` 画，不进盒模型；2x 屏降到 0.5px。 | 边框色随底色自动对，深浅两套只写一次。 |
| 阴影 | 三档 sm / md / lg 都是"近距 + 远距"两层；浮层是双环：浅色外环 1px 边框色，深色改成内环 1px 白 10%，外环去掉。 | 我们设计稿后来那层覆盖做的就是这件事（shadow-1/2/3，深色 1px 白描边），方向对，数值换它的。 |
| 单边框原则 | 一条视线最多穿过一层闭合边框。外层已经是实体（输入框、弹窗、代码块）的，里面的按钮一律 ghost 或填充，不再描边。正文无框，用户气泡无框只有底色。 | 这是"去掉套娃边框"的规则本身，比任何颜色值都重要。 |
| 圆角 | 一把尺：2 / 4 / 6 / 8 / 10 / 12 / 16，pill 999。2.0 把输入框从 20 收到 12（紧凑）/ 14（舒适），基础控件 6 / 8。卡片圆角 = 基础圆角 + 4px，保证同心。 | 我们设计稿的 16 / 18 / 20 三种卡片圆角合并成一个令牌加同心公式。 |
| 控件高度 | 紧凑 24、舒适 32，内嵌控件 18 / 22，图标 16 / 20。 | 密度是一个开关，不是两套样式。 |
| 字号 | 七档，正文 body 13–14px / 行高 1.46，长文 prose 14–16px / 1.43–1.5，标题 20px，脚注 12，说明 11。全部系统字体栈，CJK 回退 PingFang SC / TC、Hiragino、Apple SD Gothic。 | 我们正文是产品，取 prose 档的上限 16 / 1.75（中文要比它松），UI 取 body 14。 |
| 节奏 | 轮与轮之间 0.75 行，同轮内 0.5 行，正文列最大 42 / 48rem，助手正文左缩进 4px、右侧留 `clamp(0, (100% - 384px) * .175, 56px)`。 | 间距从行高派生，不另起一套数字。 |
| 时长与缓动 | 60 / 120 / 200 / 300 / 450ms 五档；缓动一组：swift `.16,1,.3,1`、expand `.19,1,.22,1`、enter `.22,1,.36,1`、overshoot `.34,1.3,.64,1`、pulse `.4,0,.2,1`。 | 我们设计稿只有一条 `.2,.8,.2,1`，加时长五档就够，弹性曲线先不要。 |
| 等待 | 三个 3px 点、间距 3.5px、1.9s 循环、错开 150ms；状态行进出 `translateY(6px → 0)` 240ms。 | 设计稿的 settle 三个点就是这个，常数换它的。 |
| 深色字重 | 深色下可变字体字重减 30–40（400 → 360）。 | 系统字体没有 wght 轴，记下，不做。 |
| 容器查询 | 不用视口媒体查询，用 `@container`，四档 576 / 480 / 384 / 320 逐级收文字、收快捷键角标、收间距。 | 我们设计稿已经用 `@container app (min-width: 900px)`，方向一致。 |
| 滚动渐隐 | 28px，`animation-timeline: scroll(self)` 驱动的七档非线性遮罩，触顶触底归零，零 JS。 | 我们头部与 dock 用的是渐变底色，不是遮罩；长局目录面板可以用这个。 |

## 二、不拿的

- 陶土橙 `#d97757` 与品牌色 `#c6613f`。这是它的品牌，不是地基。我们的品牌槽先留空：主按钮近黑，强调色只剩 destructive。
- 每个字符进场的 6px 模糊消解。中文正文按 delta 批量到达，逐字动画在 100 tokens/s 下是负担，设计稿的做法是光标，够了。
- Framer Motion 弹簧、`linear()` 十五阶按压曲线、骨架屏 105° 扫光、呼吸灯。装饰层，等有品牌再说。
- Tailwind 配置。令牌是 CSS 变量，我们直接写 CSS。

## 三、它的工作方式里有一样值得学

仓库带 `AGENTS.md`、`.cursorrules` 和一个 `scripts/check-tokens.mjs`：断言文档里引用的每个 `--cds-*` 都在 CSS 里有定义，当 CI 门禁。它的读者就是写前端的 agent。我们的令牌文件也该是这个形状：一个 CSS 文件是唯一事实，README 或 client-shape 里只引用名字，一个 20 行脚本保证引用不漂。

## 四、对我们令牌文件的结论

地基的结构取 CDS，不取它的颜色：四层 surface 灰阶、alpha 边框、三档双层阴影加深色内环、一把圆角尺加同心公式、密度开关、从行高派生的间距、五档时长一条缓动、系统字体栈。品牌是之后在这层上面点的那一笔，现在不点。这和此前提的 shadcn neutral 并不冲突：shadcn 是通用形，CDS 是同一形在对话产品上多走了一步（四层底、正文缩进、轮间距）。两者都对，取 CDS 的结构、shadcn 的克制。

协议零改动。
