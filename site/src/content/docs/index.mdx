Effect Tavern is a ground-up full-stack harness for AI roleplay and interactive fiction, built on **Effect v4**, **Solid 2.0**, **UI SDK (`@ui-sdk`)**, and **Bun**.

Instead of relying on prompt incantations, chat-depth injections, and regex scrapers, Effect Tavern treats every card as **declarative data plus deterministic rules**. Code owns the control loop, seeded dice, state transitions, and prompt-cache boundaries; the LLM is called only at typed stage seams to classify, narrate prose, and extract structured facts.

## Quick Start

**Prerequisites:** Bun `>= 1.4.4`, Node.js `>= 24`, and Vite+ (`vp`, `pnpm@12.11.1`).

<Steps>
  <Step title="Install workspace dependencies">
    ```sh
    vp install
    ```
  </Step>
  <Step title="Start the full-stack web workspace">
    ```sh
    bun --bun vp run dev
    ```
    Opens the Solid 2.0 client with HMR and an in-process `/api` session backed by `.dev/tavern.db`. Set `MODEL=fake` to run without spending API tokens.
  </Step>
  <Step title="Or play and inspect from the terminal">
    ```sh
    MODEL=fake bun run tavern play wuxia --greeting 0 --input "走进竹林"
    bun packages/runtime/bin/card.ts check wuxia
    ```
  </Step>
  <Step title="Run static checks & verification">
    ```sh
    vp check
    vp run verify
    cd packages/client && vp run verify:ui
    ```
  </Step>
</Steps>

## Built-in Template & Sample Cards

Four canonical YAML template cards live in `packages/runtime/cards/` (with full-length remasters such as `samples/life-of-pi/life-of-pi.yaml` alongside them)—serving simultaneously as starter scaffolds, architectural exemplars, and live regression suites:

| Card ID | Mode & Channel | Demonstrates |
| --- | --- | --- |
| `banxing` | `participant` / `act` | Pure chat card with zero rules or lore; voice-sample `fiction` fragment |
| `ri` | `participant` / `act` | Multi-stage `scale` bands, `hidden` route switches, 3 openings, latching readout |
| `wuxia` | `participant` / `act` | Action rolls, readout bands, 3-layer lore, `director`, `world` record & table, `guard` |
| `yandao` | `author` / `note` | Protagonist-free world simulation with card-owned `pov` slot and turn-1 window |
| `life-of-pi` (`samples/`) | `participant` / `act` | Multi-day time loop with post-record `passages`, `digest` epoch boundaries & `end: true` |
