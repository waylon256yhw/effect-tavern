Effect Tavern 是从零设计的 AI 角色扮演与交互叙事全栈系统，基于 **Effect v4**、**Solid 2.0** 与 **Bun** 构建。

它彻底摒弃了“提示词魔咒 + 聊天楼层深度插入 + 正则解析状态栏”的传统做法，将每张卡定义为**声明式数据加确定性规则**。代码掌控执行循环、带种子的随机掷骰、状态变更与缓存前缀断点；LLM 只在类型严密的阶段接缝上被调用，负责分类判断、渲染散文与提取结构化事实。

## 快速上手

**环境要求：** Bun `>= 1.4.4`、Node.js `>= 24` 以及 Vite+（`vp`，`pnpm@12.11.1`）。

<Steps>
  <Step title="安装依赖">
    ```sh
    vp install
    ```
  </Step>
  <Step title="启动全栈 Web 开发环境">
    ```sh
    bun --bun vp run dev
    ```
    同一进程内挂载 Solid 2.0 前端（HMR）与 `/api` 会话接口（默认库 `.dev/tavern.db`）。传入 `MODEL=fake` 可在不消耗 API Token 的情况下走通完整流程。
  </Step>
  <Step title="或在终端直接游玩与校验卡片">
    ```sh
    MODEL=fake bun run tavern play wuxia --greeting 0 --input "走进竹林"
    bun packages/runtime/bin/card.ts check wuxia
    ```
  </Step>
  <Step title="运行静态检查与全仓自检">
    ```sh
    vp check
    vp run verify
    ```
  </Step>
</Steps>

## 内置四张标准模板卡

`packages/runtime/cards/` 下的四张 YAML 卡既是创建脚手架与文档范例，也是运行时的回归基线：

| 卡片 ID | 视角与默认通道 | 覆盖机制 |
| --- | --- | --- |
| `banxing`（伴星） | `participant` / `act` | 纯聊天卡（零规则、零 lore），演示对白声音样本 `fiction` 片段 |
| `ri`（理） | `participant` / `act` | 单轴多段 `scale` 散文分段、`hidden` 隐藏结局开关、三开场与锁存型读数 |
| `wuxia`（竹林） | `participant` / `act` | 动作掷骰、读数分段、三层 lore、`director`、`world` 记录与人物表、`guard` |
| `yandao`（盐道） | `author` / `note` | 无玩家角色的大世界续写，卡片接管 `pov` 槽位并在第 1 轮开窗 |
